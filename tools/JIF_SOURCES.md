# Publication-card JIF sources

The cards show the **Journal Impact Factor (JIF) for the year printed in the
publication venue**, not a score for the individual article. A 2026 JIF is not
yet available: the 2026 JCR release contains 2025 JIF data, so 2026 publication
cards explicitly show **2025 JIF**. See [Clarivate's 2026 JCR release](https://clarivate.com/academia-government/blog/journal-citation-reports-2026-supporting-transparent-responsible-journal-evaluation/).

These openly available source pages reproduce JIF figures. The official JCR
database is subscription-gated, so the numbers should be rechecked there if an
institutional account becomes available. Do not silently substitute Chinese
core impact factors, CiteScore, SJR, or a paper-level metric for JIF.
